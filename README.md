# Lanzador de dados

Aplicación Android sencilla realizada para la actividad **AEA1 — Aplicació Android senzilla**

## ¿Qué hace la aplicación?

La aplicación simula el lanzamiento de un dado de seis caras. Al pulsar el botón **Lanzar dado**, genera un número aleatorio entre **1 y 6**, ambos incluidos, y lo muestra en pantalla.

Se puede pulsar el botón tantas veces como se quiera. Un resultado puede repetirse en lanzamientos consecutivos, igual que con un dado real.

## Tecnologías utilizadas

- **Kotlin** para programar la acción del botón y generar el número aleatorio.
- **XML** para definir la interfaz gráfica.
- **ConstraintLayout** para organizar los elementos de la pantalla.
- **Android Studio** como entorno de desarrollo.

## Archivos principales

- `MainActivity.kt`: contiene la lógica de la aplicación y la respuesta al pulsar el botón.
- `activity_main.xml`: define el título, las instrucciones, el resultado y el botón.
- `strings.xml`: contiene los textos de la aplicación.

## Cómo ejecutar el proyecto

1. Clonar este repositorio o descargarlo como ZIP y descomprimirlo.
2. Abrir la carpeta principal del proyecto con Android Studio.
3. Esperar a que termine la sincronización de Gradle e instalar los componentes del SDK que solicite el proyecto.
4. Seleccionar un emulador o un dispositivo Android conectado.
5. Pulsar **Run** para instalar y abrir la aplicación.
6. Pulsar **Lanzar dado** para obtener un resultado.
